## 红过的那一步（环境问题，不是代码问题）

第一次 `ci_local full` 报 **6/8**：`pytest 全量` 与 `live_ui_check` 同型失败
`FileNotFoundError: [WinError 2]`。两条失败路径的共同点是 `sync_playwright()` 要起
它自带的 node driver —— venv 里 `playwright\driver\node.exe` 被清掉了（半截 pip / 杀软都可能），
于是 E2E 段与真浏览器门禁一起塌，而探针/场景/演练全绿，极易误读成"代码红了"。

修法（同版本对齐锁文件）：`pip install --force-reinstall --no-deps playwright==1.62.0` +
`python -m playwright install chromium`（补回第三级降级的 headless_shell 114.5 MB）。
三级降级链逐级验证：msedge ✓ / chrome ✓ / 自带 chromium ✓。坑已写入 AGENTS.md「容易踩的坑」。
